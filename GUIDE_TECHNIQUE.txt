## 📊 RÉPONSES AUX QUESTIONS TECHNIQUES

### 🏗️ ARCHITECTURE & TECHNOLOGIES

**Q: Quelles technologies avez-vous utilisées pour le backend ?**
R: 
- **Framework** : FastAPI 0.115.0 (Python 3.11+)
- **ORM** : SQLAlchemy 2.0.36 (moderne avec async support)
- **Base de données** : PostgreSQL 15+ (relationnelle, robuste)
- **Validation** : Pydantic 2.10.4 (validation stricte des données)
- **Auth** : JWT avec python-jose + bcrypt (sécurité stateless)
- **Server** : Uvicorn (ASGI haute performance)

**Q: Quelles technologies pour le frontend ?**
R:
- **Framework** : React 19 (dernière version, concurrent features)
- **Build tool** : Vite 7 (dev server ultra-rapide, HMR)
- **Routing** : React Router 7 (navigation SPA moderne)
- **Styling** : CSS moderne (glassmorphism, animations, responsive)
- **Tests** : Vitest + Testing Library (moderne, compatibilité Vite)

**Q: Quelle base de données et pourquoi ?**
R:
- **PostgreSQL 15+** choisi pour :
  * Robustesse et fiabilité (ACID compliance)
  * Support JSON natif (flexibilité)
  * Performance avec index avancés
  * Compatibilité SQLAlchemy excellente
  * Standard industrie pour e-commerce

### 🔄 CI/CD & QUALITÉ

**Q: Quels tests sont dans la CI ?**
R: 
- **test.yml** : Tous les tests backend (pytest) + frontend (vitest)
- **lint.yml** : Qualité code (ruff, black, isort, eslint)
- **frontend.yml** : Tests spécifiques frontend avec coverage

**Q: Comment fonctionne votre pipeline CI/CD ?**
R:
1. **Trigger** : Push/PR sur main/develop
2. **Setup** : Python 3.11 & 3.12, Node.js 18+
3. **Install** : Dependencies backend + frontend
4. **Tests** : pytest + vitest en parallèle
5. **Quality** : Linting + formatage
6. **Status** : Badges temps réel sur README

**Q: Quelle stratégie de branches ?**
R:
- **main** : Production stable, protected branch
- **develop** : Intégration continue, tests automatiques
- **feature/** : Développement isolé, PR obligatoires
- **fix/** : Corrections urgentes

### 🏗️ ARCHITECTURE DÉTAILLÉE

**Q: Comment est structurée votre architecture backend ?**
R:
```
backend/
├── app.py              # Point d'entrée FastAPI
├── models_sql.py       # Modèles SQLAlchemy (ORM)
├── routers/           # Endpoints API REST

│   ├── products.py    # CRUD produits
│   ├── cart.py        # Gestion panier

│   └── stats.py       # Statistiques temps réel
├── repositories/      # Couche d'accès données
├── schemas/           # Validation Pydantic
└── auth/             # JWT & sécurité
```

**Q: Architecture frontend ?**
R:
```
frontend/src/
├── pages/            # Pages principales (routing)
│   ├── Home.jsx     # Accueil avec stats animées
│   ├── Products.jsx # Catalogue avec filtres
│   └── Checkout.jsx # Processus paiement

├── contexts/        # State management (Auth, Cart)

```
