### 3. 🏗️ ARCHITECTURE & CONCEPTION
==============================================

🛠️ **Stack technique choisie** :
- **Backend** : FastAPI 0.115.0 (Python 3.11+)
- **Frontend** : React 19 + Vite 7 + React Router
- **Base de données** : PostgreSQL + SQLAlchemy 2.0
- **Infrastructure** : Docker Compose
- **Tests** : pytest (backend) + Vitest (frontend)

🏗️ **Architecture en couches** :
```
Frontend React ↔ API REST FastAPI ↔ Services ↔ Repositories ↔ PostgreSQL
```

📦 **Containerisation** :
- Docker Compose pour orchestration
- Services isolés : frontend, backend, database
- Configuration production-ready
