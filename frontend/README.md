# Frontend (placeholder)

This folder will contain the React frontend for EcomNova.

Quick start (for contributors):

- Install Node.js (LTS) and a package manager (npm or yarn).
- Create the React app (example):

  npx create-react-app frontend --template cra-template-pwa

- Start the dev server from the `frontend` folder:

  npm start

Notes
- This repository currently focuses on the backend. The frontend README is a placeholder to guide future contributors.
